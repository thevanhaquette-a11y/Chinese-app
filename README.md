# 學中文 · Traditional Chinese

Mobile-friendly app to learn Traditional Chinese ⇄ English: vocabulary, grammar, exercises, tests and a "My mistakes" tab.

- Everything is in `index.html` (no build step).
- `server.js` is a tiny Node server so the app can run on Railway.
- Progress is saved in each person's browser (localStorage), so everyone has their own progress.

## Run locally
```
npm start
```
Then open http://localhost:3000
